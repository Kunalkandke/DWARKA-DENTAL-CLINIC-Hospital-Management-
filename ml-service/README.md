# ml-service – Dental X-ray Analysis API

FastAPI service that runs a YOLO11m model trained on panoramic dental X-rays.  
It exposes `GET /health`, `POST /predict`, and `POST /analyze` (legacy alias).

---

## Requirements

| Component | Version |
|-----------|---------|
| Python | **3.10, 3.11, or 3.12** (3.11 recommended) |
| CUDA (optional) | 11.8 or 12.x for GPU inference |

> ⚠️ **Python 3.13 and 3.14 are not yet supported.** numpy and ultralytics do not ship pre-built wheels for those versions. You must use Python 3.11 or 3.12.

> The `best.pt` weights file must be present inside `ml-service/` before starting the service.

---

## Setup

### 1 – Create and activate a virtual environment

```bash
# From the repository root
python -m venv ml-service/.venv

# Windows (PowerShell)
ml-service\.venv\Scripts\Activate.ps1

# macOS / Linux
source ml-service/.venv/bin/activate
```

### 2 – Install dependencies

```bash
pip install -r ml-service/requirements.txt
```

### 3 – Configure environment variables

```bash
cp ml-service/.env.example ml-service/.env
# Edit .env with your values, then export them:

# Windows (PowerShell)
Get-Content ml-service/.env | ForEach-Object {
    if ($_ -match '^([^#][^=]*)=(.*)$') { [System.Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim()) }
}

# macOS / Linux
export $(grep -v '^#' ml-service/.env | xargs)
```

The defaults in `.env.example` work out of the box if `best.pt` is inside `ml-service/`.

---

## Running the service

```bash
# From the repository root, with the venv active
uvicorn app:app --host 127.0.0.1 --port 8000 --app-dir ml-service
```

Or from inside the `ml-service/` directory:

```bash
cd ml-service
uvicorn app:app --host 127.0.0.1 --port 8000
```

The server starts on `http://127.0.0.1:8000`.  
Interactive API docs are available at `http://127.0.0.1:8000/docs`.

## Endpoints

### `GET /health`

Always public (no API key required).

```json
{
  "status": "ok",
  "model_loaded": true,
  "classes": ["Fillings", "Implant", "Cavity", "Impacted Tooth"]
}
```

---

### `POST /predict`

Accepts a `multipart/form-data` body with a single field named **`file`** (JPG or PNG, ≤ 10 MB).  
If `ML_API_KEY` is set, include the header `x-api-key: <key>`.

#### Response shape

```jsonc
{
  "modelVersion": "yolo11m-dental-v1",
  "result": "cavity",            // "cavity" | "findings_detected" | "normal"
  "confidence": 0.8423,          // highest single detection confidence, or 0
  "count": 2,
  "summary": "Detected 1 Cavity and 1 Fillings.",
  "suggestions": [
    "Possible caries detected. A clinical examination ...",
    "Existing restoration observed. Monitor for ..."
  ],
  "findings": [
    {
      "label": "Cavity",
      "confidence": 0.8423,
      "box": [120.5, 200.3, 310.1, 410.7],
      "suggestion": "Possible caries detected ..."
    }
  ],
  "imageWidth": 1280,
  "imageHeight": 640,
  "annotatedImage": "data:image/png;base64,iVBORw0KGgo...",
  "disclaimer": "This output is generated by an AI model ..."
}
```

### `POST /analyze`  _(legacy alias)_

Identical to `/predict` – kept for backward compatibility.

## Validation rules

| Rule | Behaviour |
|------|-----------|
| File type | Only `.jpg` / `.jpeg` / `.png` accepted |
| Max size | 10 MB |
| Image decode | Must be a valid image (not corrupted) |
| Grayscale check | Mean channel difference > 20 → rejected as "not an X-ray" |

All validation failures return **HTTP 400** with a descriptive `detail` message.

---

## Authentication

Set `ML_API_KEY` in your environment.  Every request except `/health` must include:

```
x-api-key: your-secret-key
```

Missing or wrong key → **HTTP 401**.

## curl examples

### Health check

```bash
curl http://127.0.0.1:8000/health
```

### Predict (no auth)

```bash
curl -X POST http://127.0.0.1:8000/predict \
     -F "file=@/path/to/xray.jpg"
```

### Predict (with API key)

```bash
curl -X POST http://127.0.0.1:8000/predict \
     -H "x-api-key: your-secret-key" \
     -F "file=@/path/to/xray.jpg"
```

### Predict and save the annotated image

```bash
curl -X POST http://127.0.0.1:8000/predict \
     -H "x-api-key: your-secret-key" \
     -F "file=@/path/to/xray.jpg" \
  | python -c "
import sys, json, base64
r = json.load(sys.stdin)
print('Result:', r['result'], '| Confidence:', r['confidence'])
print('Summary:', r['summary'])
img_data = r['annotatedImage'].split(',')[1]
with open('annotated.png', 'wb') as f:
    f.write(base64.b64decode(img_data))
print('Annotated image saved to annotated.png')
"
```

## Notes

- The model is loaded **once** at startup. Startup logs confirm success or failure.
- Inference runs in a thread pool via `run_in_threadpool` so it does not block the async event loop.
- `best.pt` is never modified by the service.
- Do **not** use `*` for `ALLOWED_ORIGINS`; list specific origins only.
